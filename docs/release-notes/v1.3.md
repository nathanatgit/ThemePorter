## Saved tweaks

Getting a pack to look right is rarely one sitting. A shape, a tint, a blend mode, then a pass over the icons that still don't match — and until now, closing the app threw all of it away. Reopening the same pack tomorrow meant starting from the top.

The home screen now has a **Saved tweaks** gallery. Each card shows the icons as they actually looked when it was saved, so you recognise a set at a glance rather than by file name.

- **Building saves automatically.** The point at which the work is worth keeping is the point you export it, so no extra step is needed. **Save tweaks** on the configure screen is there for parking a half-finished set.
- **Tap a card to carry on editing.** Long-press for **Edit**, **Build** and **Remove** — Build goes straight from the gallery to a finished theme.
- **What's kept:** the theme's names, author and description, the shape and composition, the tint colour, strength and blend mode, every per-icon tone curve, every manual icon assignment, the wallpaper choice and the output file name.
- **The pack or theme itself is not copied.** An icon-pack APK or an `.mtz` runs to tens of megabytes, and copying one per saved set would cost more storage than the themes they build, so a saved set points at the file it came from. If that file is later moved, deleted or uninstalled, the app says so and asks you to import it again — the tweaks are still there to carry on from.
- **Removing a saved set removes only the set.** The pack it was made from, and any theme already built from it, are left alone.

## Normalize keeps the curve you drew

**Normalize** pulls a group of selected icons to the same average brightness. It used to do that from scratch, which quietly discarded any tone curve you had already drawn over them.

It now measures the icons as they look right now and shifts the curve you drew by that amount instead of replacing it. Draw the shape you want, then even the group out — in either order, and as many times as you like.
