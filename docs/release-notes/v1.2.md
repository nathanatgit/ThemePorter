## Tint, reworked

Icon packs are rarely internally consistent. Some glyphs arrive bright, some almost black, and one tint colour lands differently on every one of them. This release turns tinting from a single slider into a system for making a mixed pack look like one set.

**Four blend modes** now decide how an icon's own grayscale shading meets the tint colour:

- **Multiply** — the classic. White becomes the tint, black stays black.
- **Overlay** — punchier. Darkens below mid-grey, lightens above it.
- **Soft Light** — the same idea without Overlay's hard midpoint, for a subtler recolour.
- **Lighten** — keeps whichever of the shading or the tint is brighter, which rescues artwork too dark to read once tinted.

Blend mode sets the character of the whole theme; the **tone curve** from 1.1 is what fixes the icons that still don't match. Select them in the manual-replacement grid, then drag the curve over their combined histogram — or tap **Normalize** to pull them all to the same average brightness in one step. One global look, one per-icon correction.

## Faster

Building a theme is roughly **15× faster**. A 161-icon pack with a tint and a fixed shape went from about 56 seconds to under 4 on a nubia NX733J.

Two things were behind it. The tint ran its full floating-point blend for every channel of every pixel, when the result only depends on a 0–255 grey level and one tint channel — 768 possible answers, recomputed millions of times. It is now tabulated once per image. Separately, the shaped background plate was rebuilt from scratch for every icon in the pack, though it is identical for all of them; it is now built once.

The in-app preview got the same treatment: the icon grid no longer re-renders on every tick of a slider drag, the preview tiles share one background plate instead of building one each, and the calendar and clock previews are cached.

## Fixed

- **Calendar and clock now follow the icon size, background size and composition settings.** They only ever followed the shape and tint — their frames were always composed at full size, so a 60% background or a 110% icon silently stopped at the dynamic icons. Both now go through the same rendering path as an ordinary app icon, so the settings can't drift apart again. Generated clock hands scale with the dial.
- Preview icons are a fixed set of five common apps plus the calendar and clock, always visible, rather than one icon you had to pick.
- Icon size and background size moved under a collapsible **Icon & background size** heading, since they are adjusted far less often than composition and tint.
