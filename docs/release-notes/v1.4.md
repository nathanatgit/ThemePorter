## Import several packs at once

One pack rarely covers every app on a phone. Until now an import took exactly one icon pack or theme, so an app the pack had no artwork for could only fall back to its own icon.

Importing now takes several at a time: icon-pack APKs, `.mtz` themes, or packs already installed on the phone.

- **The first one picked is the main source.** Wherever it has an icon for an app, that icon is used. It also supplies the theme's name, author and description, and the icon back, mask, calendar and clock.
- **The rest fill the gaps, in the order picked.** An app the main source has no artwork for takes its icon from the next pack that has one, before falling back to the app's own icon.
- **Any app can be switched by hand.** The icon picker under Manual replacement offers every pack's icons, with a filter at the top to show just one pack. Wallpapers from every picked theme are offered too.
- **Picking files:** select more than one file in the system file picker.
- **Installed icon packs:** long-press a pack to start selecting, then tap to add or remove others. The number on each row is its order, and 1 is the main source. Tap **Import** when done, or press Back to clear the selection. A plain tap with nothing selected still imports that one pack straight away.
- **Saved tweaks remember every pack**, in order, so reopening one brings back icons picked from the extra packs as well. If any of those packs has been moved or uninstalled since, the app names it and asks you to import again.

## Fixes

- **A user app's preview now matches the build.** Where a pack has two drawables for the same activity, the app list previewed the last one while the theme was built with the first, so a tone curve drawn on that cell could miss the icon actually written. Both now use the first.
- **No more wrong icons after switching sources.** A preview still decoding from the previous pack or theme could land in the new one's cache. MTZ themes reuse the same entry names, so this could show one theme's icon in another's app list.
- **Opening several MTZ files no longer crashes.** Each one used to unpack into the same temporary file, so opening a second overwrote the first while it was still open.

## Also

- The icon picker says how many icons match in total, instead of reporting the first 900 as all there are.
- A manual **Test release** workflow builds a signed APK from any branch as a downloadable artifact, without tagging or publishing a release.
