## Import several packs at once

One pack rarely covers every app on a phone. Until now an import took exactly one icon pack or theme, so an app the pack had no artwork for could only fall back to its own icon.

Importing now takes several at a time: an icon-pack APK, an `.mtz` theme, or a pack already installed on the phone.

- **The first one picked is the main source.** It decides the defaults: which icon each app gets automatically, the theme's name, author and description, and the icon back, mask, calendar and clock.
- **The rest are extra choices.** Their icons show up in the icon picker under Manual replacement, so any app can be switched to one of them by hand. Wallpapers from every picked theme are offered as well.
- **Picking files:** select more than one file in the system file picker.
- **Installed icon packs:** long-press a pack to start selecting, then tap to add or remove others. The number on each row is its order, and 1 is the main source. Tap **Import** when done. A plain tap with nothing selected still imports that one pack straight away.

A saved tweak remembers only the main source. Reopening it brings back the main pack and everything decided about it, but not icons picked from the extra ones.

## Also

Temporary copies of imported files now each get their own name in the app's cache, so two open sources can no longer overwrite each other's files.

A manual **Test release** workflow builds a signed APK from any branch as a downloadable artifact, without tagging or publishing a release.
